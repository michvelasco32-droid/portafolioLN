🌐 Traductor Simple con Python

Explicación detallada del código usando deep_translator

📖 Introducción

Este programa es un traductor interactivo que permite convertir texto a diferentes idiomas utilizando la biblioteca deep_translator de Python. El programa solicita al usuario un texto y permite elegir entre cinco idiomas de destino.

📦 Importación de Bibliotecas

from deep_translator import GoogleTranslator

Se importa GoogleTranslator de la biblioteca deep_translator, que utiliza la API de Google Translate para realizar las traducciones de manera gratuita y sencilla.

⚙️ Función Principal: tra()

Esta función contiene toda la lógica del traductor:

1. Interfaz de Usuario

print("=" * 50) print(" Traductor simple") print("=" * 50)

Crea un encabezado visual con líneas de separación para mejorar la presentación.

2. Captura de Texto

texto = input("\nEscribe el texto a traducir: ")

Solicita al usuario que ingrese el texto que desea traducir.

3. Menú de Opciones

print("\nPresiona una tecla para elegir el idioma de destino:") print("i = Inglés") print("f = Francés") print("a = Alemán") print("y = Italiano") print("p = Portugués") print("x = Salir del programa")

Muestra un menú interactivo con los idiomas disponibles y una opción para salir.

4. Diccionario de Idiomas

idiomas = { "i": ["en", "inglés"], "f": ["fr", "francés"], "a": ["de", "alemán"], "p": ["pt", "portugués"], "y": ["it", "italiano"] }

Estructura de datos que almacena el código ISO del idioma y su nombre legible para cada opción.

5. Procesamiento de la Opción

tecla = input("Tu opción: ").lower() if tecla == "x": print("\n¡Hasta pronto!") exit()

Captura la opción del usuario y la convierte a minúsculas. Si elige 'x', el programa termina.

6. Traducción

if tecla in idiomas: codigo = idiomas[tecla][0] nombre = idiomas[tecla][1] try: traduccion = GoogleTranslator( source='auto', target=codigo ).translate(texto) print(f"\nTraducción en {nombre.upper()}:") print(traduccion) except Exception as e: print("Ocurrió un error:", e)

Si la tecla es válida, realiza la traducción usando GoogleTranslator con detección automática del idioma de origen (source='auto') y muestra el resultado.

✨ Características Principales

🔄 Detección Automática

El programa detecta automáticamente el idioma de origen.

🌍 5 Idiomas

Traduce a inglés, francés, alemán, italiano y portugués.

🔁 Bucle Infinito

Permite realizar múltiples traducciones sin reiniciar.

⚠️ Manejo de Errores

Captura excepciones para evitar que el programa falle.

🔄 Flujo del Programa

  • El bucle while True mantiene el programa en ejecución continua.
  • Se llama a la función tra() que muestra el menú.
  • El usuario ingresa el texto a traducir.
  • El usuario selecciona el idioma de destino.
  • Se realiza la traducción y se muestra el resultado.
  • El programa regresa al paso 2 para una nueva traducción.

📥 Instalación de la Biblioteca

Para usar este código, primero debes instalar la biblioteca:

pip install deep-translator
Nota: Esta biblioteca es gratuita y no requiere API key, lo que la hace ideal para proyectos educativos y personales.
